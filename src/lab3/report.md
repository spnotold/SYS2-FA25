
# Lab3 实验报告（思考题）


## 卷积加速器与整数指令的执行时间与加速比

- 计时方法：在 `conv_compute` 和 `mul_compute` 前后用 `get_time()` 读取 `mtime`，相减得到周期数（参考 `repo/sys-project/testcode/conv/main.c`）。
- 实测结果（十六进制 → 十进制）：
  - conv_time = 0x33d9 (= 13273) cycle
  - mul_time  = 0x167558 (= 1471832) cycle
  - 加速比 S = `mul_time / conv_time` ≈ 111倍（十进制）

## 卷积加速器相对整数指令的优缺点与应用场景

- 优点
  - 高吞吐、低能耗：并行乘法 + 专用加法链，效率高于通用 CPU 的位级乘加。
  - 释放 CPU：计算在加速器完成，CPU 只负责喂数/取数与轮询。
  - 时序明确：`finish`/READY 明确“结果就绪”时刻，便于流水化。
- 缺点
  - 灵活性受限：本设计核长固定为 4，更改需改 RTL 并重新综合。
  - 驱动复杂：需遵循 MMIO 协议（先读后写、零填充、读 hi/lo 等）。
  - 资源占用：乘法器与加法链消耗片上资源与时序裕量。
- 应用场景
  - DSP/FIR 一维滤波、音频去噪/特征提取。
  - 图像处理中的卷积/边缘检测/模糊（二维可由行列一维卷积组合）。
  - 神经网络（CNN）卷积层。


## 如何用卷积加速器实现乘法运算

- 思路：把 4 个核系数中 3 个设为 0，仅保留一个为被乘数 `b`；配合零填充，使输入 `a` 与该系数对齐。首个有效输出即 `a × b`。
- 操作步骤（计算 `a × b`）
  1. 写入卷积核 `[p0, p1, p2, p3] = [0, 0, 0, b]`（向 `KERNEL_REG_OFFSET` 连续写 4 次）。
  2. 喂数据序列 `0, 0, 0, a`（即常规流程中的 3 个前导 0 再喂 `a`）
  3. 第一个有效就绪时读到的 128 位结果即 `a × b`
- 连续乘法：保持核为 `[0,0,0,b]`，每隔 4 次喂入一个新的 `a`（其余为 0），即可每 4 次得到一个乘积。
